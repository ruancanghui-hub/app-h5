# 0002. 身份服务同仓独立进程，托管登录页作接入面

## Status

Accepted

## Context

要为约 99 个自有 App 复用注册/登录，候选包括：仅在本仓做登录 H5、独立身份仓库与域名、或与反馈 API 同进程。本仓已是 WebView H5 + 轻量 Node API。

## Decision

身份服务作为复用本体，与「问题反馈」同仓但独立进程/端口与数据目录；本仓托管登录页是第一个接入客户端，不把平台能力塞进反馈服务进程。

## Consequences

- 正向：复用边界清晰；反馈 API 保持薄；可先同机部署再拆仓。
- 负向：多一个 pm2 进程与反代路径；部署脚本需同时打包两套服务。
